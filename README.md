# MERLINA

**Modular Evidence Ranking and Learning for Integrated geNe Analysis**

*A modular machine learning framework for candidate gene prioritisation in rare diseases.*

## Overview

MERLINA is a computational framework developed to support candidate gene prioritisation in rare disease genomics.

The framework integrates multiple sources of evidence, including genetic variant annotations, patient phenotypes, biological knowledge, population information, and gene-level characteristics, using machine learning approaches to rank candidate genes for individual patients.

## Framework

MERLINA is organised into complementary evidence modules:

- **Variant evidence:** Variant pathogenicity predictions and functional annotations.
- **Phenotypic evidence:** Patient–gene similarity based on Human Phenotype Ontology (HPO) annotations.
- **Biological knowledge:** Gene–disease associations, biological networks, and functional relationships.
- **Population evidence:** Population allele frequencies and ancestry-aware information.
- **Gene-level evidence:** Gene constraint metrics and inheritance compatibility.
- **Evidence integration:** Machine learning models combining evidence to generate patient-specific candidate gene rankings.
